# Vala Documentation

This is the source code repository for the Vala Documentation website: https://docs.vala.dev/

> [!TIP]
> **Something missing or wrong in the docs? You can fix it.**
> 1. [Create a new issue](https://github.com/vala-lang/vala-docs/issues/new) describing the change that you would like.
> 2. Want to fix it yourself? Comment on the issue and [open a pull request](https://github.com/vala-lang/vala-docs/pulls) that references it. You're very welcome to submit a pull request for an issue you created.
>
> Not comfortable writing the change? Just create the issue. Others can pick it up.


## Contributing

- Request a change: [create an issue](https://github.com/vala-lang/vala-docs/issues/new). Please check the [existing issues](https://github.com/vala-lang/vala-docs/issues) first to avoid duplicates.
- Make the change yourself: browse the open issues, comment on one to say you're working on it, then submit a pull request that links to it. Pull requests for your own issues are encouraged.

## Build Instructions

### Requirements

- [node.js](https://nodejs.org/) version 18 or higher

### Running locally
1. Clone the repository
2. Install dependencies:
```shell
npm install
```
3. Run the dev server:
```shell
npm run docs:dev
```
4. Open http://localhost:5173/ (default url, check output of above if this does not work)
