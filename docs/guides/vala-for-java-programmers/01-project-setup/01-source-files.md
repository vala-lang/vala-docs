# 1.1. Source Files

Java: `*.java`

Vala: `*.vala`

Unlike Java, Vala file names are not tied to the types they contain, and
`valac` does not enforce a file naming convention. See
[File Naming](/tutorials/main/02-00-basics/02-01-source-files-and-compilation#file-naming)
for the conventions commonly used across Vala projects.
